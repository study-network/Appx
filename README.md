## Features
- **Batches Catalog:** Browse and search batches with exam and class filters.
- **Batch Details:** Overview, schedule items, and subjects breakdown.
- **Subject Topics:** All chapters and topics inside each subject.
- **Lectures & Notes:** Access videos, study notes, DPP PDFs, and tests.
- **Lecture Player:** Fullscreen responsive lecture playback with attachments drawer.
- **Community:** Telegram and WhatsApp alerts.
